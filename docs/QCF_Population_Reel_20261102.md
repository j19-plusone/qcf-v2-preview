# Population reel

Repository update: 2026-11-02 (Europe/Zurich).

Homepage population estimate now has a one-time vertical digit-reel entrance, triggered on first visibility. Reduced-motion users and browsers without Web Animations receive static text. Accessible numeric label remains stable; decorative digits are hidden from assistive technology.
